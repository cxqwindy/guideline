# Guideline-Grounded Verification-Refinement for Constrained Scientific Generation

This repository provides anonymized sample data and reference code for reproducing the core workflow of a guideline-grounded verification-refinement framework for constrained scientific generation.

The released materials are intended for review and reproducibility checking. To avoid data leakage and preserve anonymity, we provide:
- sample synthetic tasks;
- sample factual examples;
- sample structured guidelines;
- prompt templates;
- reference implementations of retrieval, verification, feedback mapping, and evaluation modules;
- demo scripts for running the pipeline on sample data.
